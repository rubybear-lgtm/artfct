The Problem

Sharing styled HTML output is unnecessarily hard:

🚫 Sign-up fatigue

Every hosting service requires accounts, passwords, email verification. Kills spontaneity.

📤 File-sharing overhead

Attaching HTML files to emails or Slack breaks rendering. ZIP archives, Dropbox links — friction.

🧪 Context switching

Leaving your terminal or AI agent to open a browser, upload, copy a link — expensive interruption.

🔍 Discoverability

Raw HTML code blocks in chat lose visual context. Recipients must copy, save, open locally.

✨

artfct eliminates every layer of friction between having HTML and sharing it.

How It Works

Four ways to deploy. One URL to share.

🖼️ Browser

Drag a .html or .md file onto the drop zone. Click deploy. Copy the link.

// Visit artfct.dev, drop file, done

💻 CLI

Pipe from stdout or pass a file path.

curl https://example.com/report.html | artfct deploy
artfct deploy ./dashboard.html

🌐 REST API

POST JSON. Get a URL back. Integrate anywhere.

curl -X POST https://artfct.dev/v1/artifacts \
-H "Content-Type: application/json" \
-d '{"html":"<h1>Hi</h1>","tier":"public"}'

🤖 AI Agent (MCP)

Agents call deploy_to_canvas and return a live URL.

await mcp.callTool("deploy_to_canvas", {
  html: "<h1>Hello</h1>",
  tier: "public"
})

Deployment Tiers

Choose the right level of persistence and access

public

Public

Permanent. Anyone with the URL can view. Best for shareable dashboards, reports, demos.

secure

Secure

Permanent. Authenticated users only. Best for sensitive or private content.

ephemeral

Ephemeral

Configurable TTL (default 60min, max 1440min). Auto-deletes. Best for quick previews.

// API payload
{ html: "...", tier: "ephemeral", ttl_minutes: 30 }

AI Agent Integration

Designed for the agentic era — from first principles

🧠 MCP Server

Standard JSON-RPC over stdio. Exposes deploy_to_canvas with params: html, tier, ttl_minutes. Auto-discovers Cursor, Claude Desktop, Gemini, Codex.

Architecture

Simple, fast, composable

⚙️ Hosting Engine

  • Rust on Cloudflare Workers (WASM)
  • Brotli compression before KV storage
  • Base62 URL IDs (22 chars, unguessable)
  • iframe sandbox + CSP headers
  • Rate limiting: 60 creates/min/IP

📦 CLI & MCP

  • Single Rust binary (artfct)
  • Commands: deploy, delete, mcp, setup, doctor
  • Cross-platform (macOS, Linux)
  • One-liner install script
  • Auto-configures agent MCP clients

🌐 Frontend

  • Laravel 13 + Inertia.js v3 + React 19
  • Tailwind CSS v4 + Solarized palette
  • SSR enabled via Inertia
  • Markdown-to-HTML (client + server)
  • Three pages: upload, docs, blog

🌍 Edge Delivery

  • Cloudflare Workers global network
  • KV storage for artifacts
  • Brotli → fast reads worldwide
  • CORS enabled on all endpoints
  • 1MB max payload, 24h max TTL
